# INTERACTION-DESIGN-SYSTEM
Coastal Cravings is a modern UI/UX design for a seafood restaurant ordering platform. Designed in Figma, it features an intuitive home page, food search, menu customization, cart, and checkout flow. Developed during my UI/UX Design Internship at CodTech IT Solutions (Intern ID: CT08DN1136), it emphasizes usability and responsive design.
